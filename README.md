## DMIT 补货为什么这么难等

DMIT 是 2019 年由几个华人留学生创办的 VPS 商，总部在美国，机房目前覆盖洛杉矶（LAX）、香港（HKG）、日本东京（TYO）三个地区。

它的特点是线路质量在同价位里属于顶尖——尤其是洛杉矶 CN2 GIA 线路，知名商家搬瓦工在美西方向的 CN2 GIA 路由，部分走的就是 DMIT 自建的上游线路。换句话说，DMIT 不只是在卖 VPS，它本身也是部分同行的网络上游。

正因为如此，库存才会紧张。DMIT 在超卖这件事上历来比较克制，不会为了多收钱就往宿主机塞更多虚拟机，所以每次补货的数量有限，遇上热门套餐几个小时就能见底。

洛杉矶的情况最典型。AN4 平台在早期是最受欢迎的入门级优化线路套餐，长期缺货，偶尔补一批，往往当天就卖完。今年 AN4 平台硬件资源彻底耗尽，全部下架。目前洛杉矶在售的是升级后的 AN5 平台，搭载 AMD EPYC 9005 系列 CPU，硬件性能明显强一截，代价是价格相比 AN4 时代有所上调。

## Pro vs EB：怎么选

这是问得最多的问题。

两款都是洛杉矶机房，AN5 平台硬件一样，区别完全在线路。简单来说：

**看你用什么运营商。**

- **电信用户** → Pro。电信去程走 CN2（AS4809），直连，延迟低，Pro 套餐给电信用户的体验是最完整的
- **移动用户** → EB。EB 的移动回程是 CMIN2（AS58807），这是移动自己的高端国际出口，比 Pro 里的移动路径更优
- **联通用户** → 都行，Pro 和 EB 对联通的回程都走 9929，差别不大，哪个便宜选哪个
- **三网都用/企业建站** → Pro。稳定性优先，CN2 GIA 回程对各运营商的表现最均衡

如果你只是想找一台"便宜、能稳定用"的机器，在预算有限的前提下：EB.TINY 季付 $37.99，算下来每个月大概 $12.7，1核2G + 1.5T流量，日常跑代理、建站、挂脚本够了。

不确定自己适合哪条线？直接去官网的 Looking Glass 测一下延迟，Pro 测试 IP 是 `45.90.213.1`，EB 系列有专属的延迟监控。

## DMIT 的几个注意点（避坑）

用下来踩过或者看别人踩过的几个坑，在下单前知道比下单后踩到强：

**流媒体解锁能力有限。** DMIT 洛杉矶的 IP 在 Netflix、Disney+ 等主流流媒体上的解锁率不稳定，甚至有时候完全解锁不了。如果你买 VPS 主要是为了解锁流媒体，这家不是最优选。用过的人通常提到的是拿它做线路鸡，另外配一台专门解锁流媒体的落地机。

**不支持自建邮件服务。** DMIT 封了对外 25 端口，所以没办法在上面架邮件服务器（SMTP 发信）。有自建邮局需求的要注意。

**ChatGPT 解锁不稳定。** IP 质量本身不错，但 DMIT 洛杉矶的 IP 被 OpenAI 限制访问的概率比较高，不能保证每个 IP 都能直接访问 ChatGPT。

**价格对比 AN4 时代明显提高。** AN4 年付最低几十美元的时代结束了。AN5 平台最低是季付 $37.99，约合年付 $150 左右。如果你之前是冲着 DMIT 低价去的，现在的定价需要重新评估一下是否符合预期。
